# Empire Refactored v0.126

## 0.126.12 - Settle Colony fixes
- Date: 2026-03-25
- Type: Patch
- Authors: Matathias

Adds a couple of checks and validations for the settle colony event.

### Changes
- Wraps the settleNewColony portion of Process Events in a try/catch, so we can remove the target location from the caravans list if the event fails somehow
- Adds new ValidateSettlementCaravansList function, firing daily to make sure that the settlementCaravansList has no orphaned locations

## 0.126.11 - Minor backend changes
- Date: 2026-03-25
- Type: Patch
- Authors: Matathias

Minor backend change to the static cache invalidation.

### Changes
- Publicizes the EmpireCacheUtil class and adds two functions for submods to "register" themselves, so that their global caches are automatically invalidated at the same time as Empire's

## 0.126.10 - Policy Description Fixes
- Date: 2026-03-25
- Type: Patch
- Authors: Matathias

Handful of minor fixes for policy descriptions.

### Changes
- Added displayDivisor field to FCStatDef
- FCStatModifier descriptions will divide stat values by their displayDivisor if displayDivisor is non-zero
- raidCooldownOffset and deadPawnCooldownOffset have 2500 displayDivisor (so they will show up in-game as hours instead of ticks)
- Handful of grammar and clarity fixes

## 0.126.7 - Minor changes
- Date: 2026-03-24
- Type: Patch
- Authors: Matathias

Minor backend changes.

### Changes
- Add a raidTargetingWeight field to WorldSettlementDef. Influences how likely settlements of that type are to be raided
- Slight rewrite of the raid-targeting logic to include the above field and also make use of RandomElementByWeight
- Add two functions to FCEventHandlerExtension to let events have dynamic odds of success
- Add IsOptionAvailable to FCEventHandlerExtension to let events dynamically determine if an option is available

## 0.126.5 - Minor tech level change
- Date: 2026-03-24
- Type: Patch
- Authors: Matathias

Small change to how the Empire faction's tech level is calculated.

### Changes
- Uses the player faction's tech level as a floor when determining the Empire faction's tech level. Meant to provide compatibility with techlevel-advancing mods.
