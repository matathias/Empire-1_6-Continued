# Empire Refactored v0.117

## 0.117.4 - Update settings
- Date: 2026-03-20
- Type: Minor
- Authors: Matathias

Updates the mod settings.

### Changes
- Reorganize the mod settings to put events settings and military settings in their own tabs
- Empire Events can be individually disabled in the settings

## 0.117.3 - Battle auto-resolve update
- Date: 2026-03-20
- Type: Minor
- Authors: Matathias

Changes the calculations for auto-resolve battles.

### Changes
- Adds a dampening factor to how much Military Efficiency affects the outcome of auto-resolve battles (its effect was a little too strong). The dampening factor can be changed in the settings.

## 0.117.2 - More military fixes
- Date: 2026-03-20
- Type: Patch
- Authors: Matathias

Some more fixes for the military side of Empire.

### Changes
- The "atk x / def x * <budget>" label in the main military tab is now wider, so the text shouldn't wrap
- Bugfix: deploying a squad to a map and then leaving the map before the squad does can result in the squad's settlement being stuck in the "Deployed" state
- Changed auto-resolve defense battles: if a defending settlement is being reinforced by another (e.g. through auto-defend), then the combined defensive force uses a mix of the military efficiency of the defending settlement and the reinforcing settlement

## 0.117.1 - Auto-Defense bugfixes
- Date: 2026-03-20
- Type: Hotfix
- Authors: Matathias

Fixes a couple of issues with the auto-defend feature.

### Changes
- Loosens restrictions on what settlements can auto-defend
- Bugfix: the settlementMilitaryLevel field would sometimes not update when it should, resulting in a settlement that *should* be auto-defending, not actually being chosen to auto-defend

## 0.117.0 - Event Def Upate
- Date: 2026-03-19
- Type: Minor
- Authors: Matathias

Updates the FCEventDef with some extra filtering options.

### Changes
- Adds a 'allowedSettlementTypes' and 'blockedSettlementTypes' fields to FCEventDef
