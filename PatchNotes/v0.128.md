# Empire Refactored v0.128

## 0.128.8 - Minor Fixes
- Date: 2026-03-26
- Type: Patch
- Authors: Matathias

Adds a couple more DLC checks for DLC-using code.

### Changes
- Gates two code uses of shuttles behind checks for the Royalty DLC, with a fallback option to transport pods or regular caravans

## 0.128.7 - Minor Fixes
- Date: 2026-03-26
- Type: Patch
- Authors: Matathias

Handful of minor fixes for unit importing and xenotype handling.

### Changes
- Detect when an imported unit encountered errors during loading, and mark it in the Import Units UI
- Patch out references to "Xenotypes" in the Manage Units window when Biotech isn't active

## 0.128.5 - Minor Fixes
- Date: 2026-03-26
- Type: Patch
- Authors: Matathias

Some minor fixes to make the road builder a little more robust.

### Changes
- Make sure that the settlement list is populated before processing paths

## 0.128.4 - Policy Fixes
- Date: 2026-03-26
- Type: Hotfix
- Authors: Matathias

Fixes an issue where some policies wouldn't properly apply until restarting the game.

### Changes
- Bugfix: Militaristic and Expansionist policies wouldn't correctly apply their bonuses until restarting the game

## 0.128.3 - Biotech fixes
- Date: 2026-03-26
- Type: Hotfix
- Authors: Matathias

A couple of fixes to let Empire gracefully handle not having Biotech.

### Changes
- Gate xenotype initialization behind a check for the Biotech DLC
- Don't render the xenotype filter button if Biotech is disabled/not intalled, and there is only one humanlike race

## 0.128.2 - Resource-DLC Patch
- Date: 2026-03-26
- Type: Hotfix
- Authors: Matathias

Fixes a DLC-access issue for some resources.

### Changes
- Bugfix: Deathrest capacity serum and Sentience catalyst on RTD_Medicine weren't gated behind DLC checks, causing problems for players without those DLC
- Updated several other items to also check for DLC

## 0.128.1 - "Ghost" Caravan Fixes
- Date: 2026-03-26
- Type: Hotfix
- Authors: Matathias

Fixes a couple of issues that might cause "Ghost" caravans

### Changes
- If a delivery good can't be added to a pawn for some reason, then it is placed at the tax spot, instead of silently destroyed
- Tax delivery method is locked in at event creation time, rather than delivery time

## 0.128.0 - Military Backend Changes
- Date: 2026-03-25
- Type: Minor
- Authors: Matathias

Handful of changes to the military backend for submod support.

### Changes
- Add RaidWeightRegistry and associated interface, for submods to influence the raid weighting for Empire settlements
- Add UnitOverlayRegistry and associated interface, for submods to add information to the military squad screen
- Add MercenaryDeathEvent, for submods to potentially intercept mercenary deaths
