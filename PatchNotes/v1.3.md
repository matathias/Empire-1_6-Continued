## 1.3.71 - Save-Load Bugfix
- Date: 2026-06-02
- Type: Patch
- Authors: Matathias

Fixes a bug where an entirely-derived list is still saved and loaded, introducing the possibility for a corrupted save or weird behavior to null it out. This then causes crashes and issues later on.

### Changes
- Don't scribe FactionFC.factionResources. It's always fully rebuilt after loading, so saving it is pointless

## 1.3.70 - Settlement Cost Fixes
- Date: 2026-05-25
- Type: Patch
- Authors: Matathias

The SettlementTypeExtension would cache a reference to the main world component, but never invalidate it. This could lead to things like settlement cost evaluations referring to the wrong world component. This update fixes that, and a couple of other minor issues.

### Changes
- Don't cache the FactionFC WorldComponent in SettlementTypeExtension
- Skip invalid events in ValidateSettlementCaravansList()
- Snapshot settlement cost in the settle confirmation dialog so the actual cost paid matches what the user sees in all cases

## 1.3.59 - Reduce VRAM usage
- Date: 2026-05-07
- Type: Patch
- Authors: Matathias

Did you know that many of Empire's textures were over 1000 pixels on a side? I sure didn't. But thanks to that, Empire would use a whopping 600MB+ of VRAM!

This patch shrinks all those icons to more reasonable sizes, thereby reducing Empire's VRAM usage to only about 36MB.

### Changes
- Shrink faction icons to 256x256, and shrink trait icons to 128x128
- Remove redundant texture loads in TexLoad

## 1.3.39 - Caravan Gizmo Update 2
- Date: 2026-04-24
- Type: Patch
- Authors: Matathias

Rimworld logic says that a battle is over as soon as hostiles start to flee; this is when the Reform Caravan gizmo appears. Empire, however, does not consider a battle to be over until all hostiles have died or fled the map. This creates an awkward interim period where the gizmo appears, but isn't fully usable. This update resolves that by disabling the gizmo until Empire says the battle is over.

### Changes
- Bugfix: the Reform Caravan gizmo can appear before Empire says the battle is actually over
