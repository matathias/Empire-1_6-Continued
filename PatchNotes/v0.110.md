# Empire Refactored v0.110

## 0.110.0 - New weapontags
- Date: 2026-03-18
- Type: Minor
- Authors: Matathias

Adds a couple of weapon tags that can be used to block a weapon from appearing in the weapon list for mercs.

### Changes
- Add "FCWeaponBlocklist_Merc" weapontag to block a weapon from being choosable for mercs
- Add "FCWeaponBlocklist_Craft" weapontag to more generally block a weapon from being crafted
