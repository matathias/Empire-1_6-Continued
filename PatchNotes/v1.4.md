- Type: Patch

## 1.4.13 - More Backend Updates
- Date: 2026-04-23
- Type: Patch
- Authors: Matathias

Changes all fields that refer to a planet tile to use the actual PlanetTile type. Rimworld does technically allow for straight casting between int and PlanetTile, but you lose layer information when you do that. Empire actually does handle multiple layers (see orbital settlements), so switching over to using the actual PlanetTile type should protect against future errors.

### Changes
- Update to use actual PlanetTile type wherever appropriate

## 1.4.11 - Policy Update
- Date: 2026-04-22
- Type: Minor
- Authors: Matathias

The first real balance pass. This patch updates many of the policies to (hopefully) smooth out the power level. Along with the shake-up comes a new feature: the ability to clear your chosen policies and select new ones, albeit for a cost.

### Changes
- Militaristic policy nerfed: 1.2 military efficiency -> 1.1, extra squad cost 20% -> 40%, military building upkeep reduction 100 -> 50, and the policy now carries an inherent -0.5 happiness per day. People generally don't like living in militaristic regimes, after all
- Pacifist policy buff/nerfed: no longer immune to soldier deaths (no idea why that was even a thing); in exchange, the diplomatic envoy is slightly more likely to succeed, and the relation improvement range has been changed from 5-15 to 8-20
- Egalitarian changed: removed happiness-based tax bonus as well as starting happiness penalty. Added 10% worker production bonus, 1 additional worker per level, -3 overmax workers, worker base cost increased by 10
- Expansionist changed: no more free starting settlement, no more 50% discount once per year. Instead, all settlements are 25% cheaper, but start at 75% prosperity. Threat scaling increased by 10% as well
- Technocratic nerfed: now carries a -10% penalty to base tax percentage
- Slaver nerfed: -0.5 happiness and +0.5 unrest per day. You don't get to rely on slave labor for free, bucko (and the +2 workers per settlement level *is* quite strong)
- Scorched Earth Doctrine buffed: building destruction chance 2x -> 1.25x, defending bonus 1.3x -> 1.5x, prosperity loss on victory 1.5x -> 1.2x
- Added option to clear policy choices after they've already been chosen, for a cost that scales based on Empire size and prosperity
