# Empire Refactored v0.100

## 0.100.1 - Additional extensibility support
- Date: 2026-03-16
- Type: Minor
- Authors: Matathias

Lets submods 'inject' extra value into a settlement's tithe budget.

### Changes
- Adds an ITitheBudgetModifier interface that WorldObjectComps can implement. Allows for 'injection' of additional value into a settlement's tithe budget for a given resource

## 0.100.0 - Major Refactor
- Date: 2026-03-16
- Type: Major
- Authors: Matathias, Pecha

Updating version during major refactor.

### Changes
- Reworked FactionColonies class and the settings
- Added a LogUtil class
- Refactored settlements to use a single WorldSettlementFC class
- Settlement types and resources defined through XML defs
- Major UI rework (redid most of the mod's windows)
- Road buildings uses a Minimum Spanning Tree (MST) for more organic-looking road networks
- Faction policies and traits converted into defs
- Repurposed old, unused policies into three new categories of Edicts
- Reworked events to give the player a choice over how they respond
- Reworked taxes: a snapshot of a settlement's production is taken each day. At tax time, the player recieves taxes based on the average of these daily snapshots
- Numerous bug fixes to the manual battle system. It has been tentatively re-enabled. If it remains buggy, it may be disabled again
- Military threat levels reworked. Settlement raids scale more
- Numerous changes in the name of extensibility (refer to the Docs)
- Compatibility patches for Humanoid Alien Races, Combat Extended, RimWar, World Domination, and Faction Territories & Vassalage. Some still need testing
- Numerous other bugfixes; too many to note here
