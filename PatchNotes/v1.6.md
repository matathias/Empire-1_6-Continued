## 1.6.33 - Settlement Destruction Update
- Date: 2026-09-06
- Type: Patch
- Authors: Matathias

Empire is coded defensively when it comes to settlement destruction, in that it prevents the actual destruction unless Empire does it itself. It's a bit *too* jealous in its defense, though, causing errors when RimWorld itself tries to clean up a corrupted settlement.

It shouldn't be possible to hit this issue through legitimate play, but a hole is a hole. This patch makes the destroy handling a little more robust.

### Changes
- Allow Empire settlements to be destroyed by RimWorld if they have no associated faction (the typical corruption clean-up case)
- Add a debug action to force deletion of an Empire settlement

## 1.6.28 - 'Non-Violent' Xenotype Reclassification
- Date: 2026-08-07
- Type: Patch
- Authors: Matathias

Previously, if a xenotype had *any* of shooting accuracy < 50%, melee hit chance < 50%, or melee dodge chance < 50%, then it would be classified as 'non-violent', and barred from use in the unit creator.

This patch changes the logic so that all three must be true for a xenotype to be classified as 'non-violent'. So now you can have merc units that are incapable of dodging, or shit at shooting, but still capable in the other two stats.

### Changes
- Relax the non-violent xenotype classification to require shooting accuracy < 50% AND melee hit chance < 50% AND melee dodge chance < 50%. This is independent of the check for whether or not a xenotype can do violent work

## 1.6.25 - Shuttle Port Fix
- Date: 2026-07-31
- Type: Patch
- Authors: Matathias

Settlements with a shuttle port always send their deliveries via shuttle (if both Royalty and the settings option are enabled). If the shuttle repeatedly can't find a landing location, though, then the deliveries will never actually go through. This update provides a small fix for that.

### Changes
- Shuttle deliveries are attempted only 3 times in a row. If the shuttle can't find a place to land after the 3rd attempt, then the delivery is sent by drop pod instead.

## 1.6.23 - Power Production Update
- Date: 2026-07-28
- Type: Hotfix
- Authors: Matathias

Fixes an issue where the Wattage generated by Empire's power generator is *always* x100 of the produced power. This is a violation of how *every* other resource works in the mod, and frankly ought to have been fixed months ago. The recent daily cadence update merely made the bug more obvious.

Players on higher diffculties are likely to notice a drastic drop in power generation. This is intentional; power production should never have been so high.

### Changes
- Power production is scaled by the silver-per-resource setting instead of a flat x100.

## 1.6.4 - Minor Fixes & Features
- Date: 2026-07-02
- Type: Minor
- Authors: Matathias

A variety of minor bugfixes, changes, and features.

### Changes
- When a settlement defends itself in a manual defense battle without an assigned squad, its defenders are assembled from the player's unit designs
- Food resource is now Farming, and features all resources that can be harvested from plants (except for medicine and drugs, which continue to belong to the Medicine resource (except for beer))
- The Mining resource now only allows rock types belonging to the settlement's tile. Obsidian is only titheable in the Lava Field biome
- Add difficulty settings for global worker base production and worker production multipliers. Higher difficulties have a harsh multiplier; lower difficulties are now swimming in resources
- Allow more than one event window to be open at a time
- When the player defeats an NPC settlement through a normal vanilla attack, they are now given the option to capture the settlement for their empire
- When generating a manual defense battle map, all turrets are stripped if the player doesn't have the tech for them. This was unnecessary for Empire itself, but *is* necessary when using other mods for base gen, such as Vanilla Base Generation Expanded
- In manual defense battles, civilian pawns' names are rendered in a muted color compared to the defender pawns, making them easier to tell apart
- Bugfix: the "Settlement Formed" letter that's sent after capturing an enemy settlement would not report the correct name
- Leathers that do not come directly from an animal (e.g. patchleather) are moved from the Animals resource to the Apparel resource. In theory, this should provide compatibility with Vanilla Factions Expanded: Midieval 2 as well
- Add a mod setting to let the player control how frequently (or infrequently) their roads build

## 1.6.2 - Production Rework
- Date: 2026-06-29
- Type: Minor
- Authors: Matathias

Reworks how resource production is calculated and displayed. All values are now calculated in per-day increments, added up each day before being disbursed on the tax tick. The net income should be the same, but the affect of mid-cycle production differences should be more obvious than the old average-of-daily-snapshots system.

Also, tithing has been slightly reworked. The tithes list is now a priority list of items. You can list more items than your settlement can afford, and when the tax tick comes, you will be sent the first N items that fit within the tithe limit.

### Changes
- Resource production rework: all values are calculated on a daily basis. The length of the tax cycle merely determines how frequently acrued production is sent to the player
- Minor tithes rework: the tithe item list is now a priority list, sending the first N items that fit within the tithe budget
