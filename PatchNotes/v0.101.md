## 0.101.1 - Fix event stacking & incompatibilities
- Date: 2026-03-17
- Type: Patch
- Authors: Matathias

Various fixes for Empire's events.

### Changes
- Update the event system so that events won't stack on the same settlement
- Update event chains to have the proper incompatible tags, so that incompatible events won't fire at the same time

## 0.101.0 - Compatibility with Vanilla Base Generation Expanded
- Date: 2026-03-17
- Type: Minor
- Authors: Matathias

Update's Empire's compatibility with Vanilla Base Generation Expanded, including a transpiler fix to an out-of-bounds error in the Vanilla Expanded Framework.

### Changes
- Add transpiler patch to fix an out-of-bounds error during VBGE map generation
- Fix the spawning of defense turrets for settlements that have weapons production
