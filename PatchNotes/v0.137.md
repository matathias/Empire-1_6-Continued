# Empire Refactored v0.137

## 0.137.1 - Debug Action Debugging
- Date: 2026-04-05
- Type: Patch
- Authors: Matathias

Fixes a couple of bugs in the debug actions.

### Changes
- Changed Create Settlement (Instant) debug action to choose settlement type first, and then enable the tile picker for the correct planet layer. This makes it possible to instantly place orbital settlements
- Fixes a bug in the Reset All Military Squads debug action that left squads orphaned, causing the squad command window to break
- Adds new debug action: Reset All Military Cooldowns, that instantly resets squad cooldown
