## 0.132.0 - Minor Events Update
- Date: 2026-03-28
- Type: Minor
- Authors: Matathias

Adds a couple of useful new fields to the Event def.

### Changes
- Adds targetAllSettlements field to FCEventDef. If true, the event targets all valid settlements
- Adds serialized list of permanent stat modifiers to WorldSettlementFC, so that settlements can track permanent stat modifiers that aren't attached to buildings or events
- Adds permanentStatModifiers field to FCEventDef. Listed modifiers will be permanently applied to all settlements affected by the event
