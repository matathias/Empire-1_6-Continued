## 1.1.9 - Orbital buildings fix
- Date: 2026-04-09
- Type: Patch
- Authors: Matathias

Fixes an issue where several orbital buildings that are supposed to be locked to one type of orbital were actually buildable in any of them.

### Changes
- Orbital Trade Hub and Space Distillery only buildable on logistics orbital platforms
- Orbital Shipyard and Orbital Surface Operations only buildable on advanced orbital platforms
- Orbital Academy and Naval Academy only buildable on glitterworld orbital platforms

## 1.1.3 - Orbital Settlement Fixes
- Date: 2026-04-08
- Type: Patch
- Authors: Matathias

A handful of fixes related to orbital settlements.

### Changes
- Bugfix: ReturnTicksToArrive() doesn't properly handle cross-layer pathfinding
- Add canBeRaided and supportsManualBattle fields to WorldSettlementDef
- Add virtual CanBeRaidedByFaction function to SettlementTypeExtension, allowing settlements to determine what kinds of factions can attack them. Defaults true
- Use the new fields/functions to make Orbital Settlements raidable only by factions with Spacer tech or above. Orbital Settlements also do not support manual battles
