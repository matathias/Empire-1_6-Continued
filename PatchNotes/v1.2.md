## 1.2.1 - Critical Fix for adding Empire mid-save
- Date: 2026-04-09
- Type: Hotfix
- Authors: Matathias

Fixes a crash when trying to add Empire mid-save. In this circumstance, Empire attempted to initialize the XenotypeFilter in the FactionFC.FinalizeInit function. As part of initializing the filter, Empire attempts to load all custom xenotypes through CustomXenotypesForReading. That calls CheckVersionAndLoad, which in turn calls InitLoadingMetaHeaderOnly. Fun fact: if the Scribe mode is *not* Inactive, then InitLoadingMetaHeaderOnly panics and force stops the scribe process. And guess what Empire's custom xenotype loading does? That's right: it calls InitLoadingMetaHeaderOnly when the Scribe mode is not Inactive. Thus, loading stops, and everything breaks. Fun.

This issue does not affect new saves.

### Changes
- Change the xenotype filter to be initialized on the first tick instead of during loading
