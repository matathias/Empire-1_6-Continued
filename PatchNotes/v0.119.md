# Empire Refactored v0.119

## 0.119.1 - Pawnkind handling fixes
- Date: 2026-03-22
- Type: Patch
- Authors: Matathias

Some behind-the-scenes fixes for pawnkind handling

### Changes
- When playing with multiple races (i.e. with HAR), Empire creates runtime pawnKindDefs for each race. But, as runtime-created defs, they cannot be resolved when loading. This fix adds a patch to loading: on encountering a 'runtime def', the def is replaced with its template version. Then, once we actually recreate the runtime def, we assign it to the pawns that need it

## 0.119.0 - FCPolicyDef update
- Date: 2026-03-21
- Type: Minor
- Authors: Matathias

Adds the ability to set required policies/traits/edicts for a new policy/trait/edict to be applied.

### Changes
- Add requiredPolicies and requirementMode fields to FCPolicyDef. If requiredPolicies is not empty, then all (or any) of the given policies must be active in order for the main def to be selectable
